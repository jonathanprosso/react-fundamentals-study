# React Fundamentals Theming

Este projeto é um estudo dos **fundamentos do React** com foco na **configuração manual de um ambiente**, sem utilizar Create React App (CRA). Toda a configuração foi feita do zero com **Webpack**, **Babel** e **styled-components**, para oferecer um entendimento profundo sobre o funcionamento interno de uma aplicação React.

---

## Objetivos do Projeto

- Configurar o Webpack manualmente  
- Entender o funcionamento do Babel e seus presets  
- Criar um ambiente React do zero  
- Estilizar componentes com `styled-components`  
- Utilizar loaders para importar arquivos CSS e outros ativos  

---

## Como rodar o projeto

1. **Clone o repositório:**

```bash
git clone https://github.com/jonathanprosso/react-fundamentals-theming.git
cd react-fundamentals-theming
```

2. **Instale as dependências:**
```bash
yarn
```

3. **Rode o projeto:**
```bash
yarn dev
```

4. **Build para produção:**
```bash
yarn build
```
