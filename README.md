# React Fundamentals Study

Este projeto é um setup básico do React com o objetivo de **entender os fundamentos** por trás da configuração de uma aplicação React moderna, **sem utilizar ferramentas como o Create React App**. A ideia é montar tudo manualmente com Babel, Webpack e outros loaders, para ter domínio total sobre o processo.

---

## Objetivos

- Aprender como configurar o Webpack manualmente
- Entender o funcionamento do Babel e seus presets
- Criar um ambiente React do zero
- Estilizar componentes usando `styled-components`
- Utilizar loaders para importar arquivos CSS
